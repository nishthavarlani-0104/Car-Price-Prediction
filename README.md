# 🚗 Car Price Prediction Using Machine Learning

This project predicts the price of used cars using various Machine Learning algorithms. The dataset was collected from Kaggle and underwent data cleaning, preprocessing, feature engineering, exploratory data analysis (EDA), and model training to build an accurate price prediction system.

---

## 📌 Project Overview

The objective of this project is to develop a machine learning model capable of predicting car prices based on different vehicle features such as manufacturer, model, year, fuel type, transmission, odometer reading, and more.

---

## 📂 Dataset

**Source:** Kaggle

**Dataset Link:**
> *https://www.kaggle.com/datasets/austinreese/craigslist-carstrucks-data/data*

## 🚀 Installation

### 1. Clone the repository

```bash
git clone <repository-link>
```

### 2. Navigate to the project folder

```bash
cd Car_Price_Prediction
```

### 3. Create a virtual environment

**Windows**

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Git Bash**

```bash
source .venv/Scripts/activate
```

**Windows PowerShell**

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install the required dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Project

Run any of the following files depending on what you want to do:

```bash
python DataSet_Overview.py
```

or

Open the Jupyter notebooks:

- `data_cleaning_EDA.ipynb`
- `DataPreprocessing_Training_Model.ipynb`

using Jupyter Notebook or VS Code.
